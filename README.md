# JFLAP
Modificación del software JFLAP.

# Atajos de teclado
- CTRL + 1....n
    Para moverte entre las diferentes herramintas, ya sea el click, nodo o transicion
- CTRL + Shift + D
  Alternar modo Oscuro (por defecto viene en negro)

## Aspectos
Con click derecho se pueden modificar las cajas de texto:
  Tamaño de la fuente 
  Tamañao de la caja de texto
  Fondo de la caja de texto
  Color de la letra

## Aceptacion de cadenas
Puede aceptar cadenas con alfabetos no "completos", por ejemplo
- [ASCV]
- [05896]
por mencionar algunos
